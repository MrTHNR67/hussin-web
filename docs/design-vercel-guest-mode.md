# تصميم: سياج على Vercel + تجربة زائر بالاسم والقبيلة

## الهدف
نقل التطبيق الحالي (الخادم + قاعدة البيانات + كل الصفحات) إلى **Vercel** حسب الطلب، مع إلغاء تسجيل الدخول: يفتح الزائر الرابط، يدخل **الاسم والقبيلة** في نفس مكان شاشة الدخول، وتبدأ التجربة. تبقى البيانات في نفس المتصفح، ويبقى التصميم وكل الصفحات كما هي.

## القرارات
1. **المنصة:** Vercel بالخادم الكامل (الخيار ب). يُغطّى Express بـ Serverless Function واحدة عبر `api/index.js`.
2. **الواجهة:** لا إعادة تصميم. نبقي HTML/CSS/الصفحات الحالية (الرئيسية، السجل، البلاغات، التقرير، الإعدادات). تُستبدل شاشة الدخول بحقول الاسم + القبيلة في نفس الموضع.
3. **الهوية:** معرّف زائر يُنشأ ويُحفظ في `localStorage` مع الاسم والقبيلة. لا كلمة مرور، لا تسجيل، لا أدوار إدارية في الواجهة.
4. **الباكند:** تُبقى نقاط API الحالية للبيانات والطقس والملفات، لكن بدون أي منطق ذكاء اصطناعي. زر «تحليل» يبقى **محاكاة بصرية ٢٫٥ ثانية في المتصفح فقط** ولا يضيف أي endpoint.
5. **الحركات (ux-motion):**
   - squash & stretch عند التنقل بين الصفحات ~120ms (على الحاوية فقط، لا على النصوص/الأرقام).
   - slow in / slow out لكل زر يفتح ويغلق: enter `cubic-bezier(0.16,1,0.3,1)`، leave `(0.7,0,0.84,0)`.
   - تكبير الأيقونات عند hover/لمس ~1.08 مع `transform-origin: center`.
   - Peak-End (الخيار ب): بعد آخر حقل في بيانات الألواح يظهر احتفال ~400ms (شعاع + stagger للعناصر، cascade <300ms)، ثم بطاقة الملخص.
   - احترام `prefers-reduced-motion` وأهداف لمس ≥44px.
6. **الطقس:** يُبقى مسار Open-Meteo الأساسي مع MET Norway كـ fallback (قد يرجع 429 من عناوين الخروج المشتركة).

## قيود Vercel وتكيّفها
- Filesystem للقراءة فقط → لا حفظ ملفات محلي: تُخزّن المرفوعات في تخزين خارجي (قاعدة البيانات أو Blob).
- كل invocation معزول → لا قاعدة SQLite محلية: يلزم Postgres خارجي مجاني (Neon/Supabase) بنفس مخطط `pg` الحالي.
- لا مهام مجدولة محلية → يُستبدل `SiyajBackup` بـ Vercel Cron إن لزم.
- كل الأسرار (`DATABASE_URL`، مفاتيح البريد/الطقس) تذهب إلى Environment Variables في Vercel ولا تُكتب في Git.

## نقاط مفتوحة
- تأكيد توفر حساب Neon أو Supabase مجاني للـ Postgres (بدون كرت).
- اختيار تخزين المرفوعات: Postgres bytea (الأبسط) أم Blob خارجي.
- مسار العمل الافتراضي: نسخة Git في `C:\Users\MOBPC\Downloads\siyaj-full-2026-10-16\siyaj-solar-guardian` (الفرع `main`).

## معايير القبول
- الرابط على Vercel يعمل، وكل الصفحات تفتح بنفس التصميم.
- لا توجد شاشة تسجيل دخول؛ الاسم + القبيلة يبدأان التجربة ويبقيان في نفس المتصفح.
- زر التحليل ٢٫٥ ثانية بصرياً فقط، وبدون أي طلب API جديد.
- الحركات الأربع تعمل على الجوال والشاشات اللمسية وتحترم `prefers-reduced-motion`.
- لا أسرار في المستودع، ونقاط API الإدارية غير مكشوفة للزائرين.
